## Batch A — fixed (server; verified on a staging copy of the live DB in WebKit + curl)
- Birthday/anniversary job: node-cron tolerance 1 h (was 1 s → skipped runs), idempotent (same text by the system account in 20 h = already posted, deleted included), startup catch-up after 8 am, family-date not UTC date (utils/dailyEvents.js, 7 tests).
- Comment purge (cron 3 am + mod purge) never hard-deletes a comment with live replies (cascade would destroy them). SQL tested on a scratch schema.
- Scheduled posts take created_at = publish_at when they go live (sorted/dated as new).
- Big News announced once (posts.big_news_notified_at, backfilled), only when published, plain @Name text.
- Notifications: changelog ✕ no longer fires DELETE /notifications/undefined; dismiss / clear-all restore rows + say so on failure; clear-all confirms; server 404s a non-numeric id.
- Referrer-Policy no-referrer → same-origin: every "back to where you were" redirect had silently never worked (comment from feed now stays on feed — verified). Referer redirects only to own /post/N (utils/safeBack.js).
- Cross-site write guard (Sec-Fetch-Site, else Origin; sibling subdomains blocked) — utils/crossSite.js; verified 403s + Origin:null login still works.
- Friendly 404 page + final error handler (was Express "Cannot GET").
- Reply parent must be a live comment on the same post; array-typed fields can't throw outside try (comments, posts create/edit, login, register); encoded redirects.
- Partial multi-photo failure no longer orphans files; push 10 s timeout; SMTP 15/30 s timeouts; deactivated members get no personal pushes.
- Push subscribe accepts only https endpoints on the real push services (utils/pushEndpoint.js); ogFetch blocks 100.64/10 (Tailscale), 198.18/15, 192.0.0/24, 224/3.
- Reaction double-tap no longer 500s (INSERT IGNORE) — verified two concurrent requests both 200.
- npm audit: critical proxy-addr + highs body-parser/brace-expansion/sharp fixed; express 4.22.3; session store forced onto app mysql2 3.24.6 (override). LEFT: nodemailer 10 (major; advisories need user-controlled attachments, not used here), ejs 7 (CLI dep chain).
